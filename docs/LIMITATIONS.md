# Current limitations

This is partial source, with read-only validate/candidates/review-page CLI commands and a local report-inspection UI. Full judging/calibration/review/replay/export orchestration is pending. CSV validation accepts the fixed eight-column schema, bounded strict decoding and explicit supported legacy overrides. Raw IDs/strings remain exact; normalization is separate. CLI inspection leaves sources unchanged and performs no model dispatch or human-ruling operation. UI counts/identities are imported report metadata; source freshness and browser interaction have not been established by the viewer.

Quantity parsing supports declared code units, complete decimal expressions and optional integer pack prefixes. Bare ounces are ambiguous; US fluid ounces are an explicit default that can be rejected. Unknown quantity/brand data is not equality. Price is nonnegative Decimal metadata. Neither raw relatedness nor native confidence is a correctness probability.

Candidate retrieval uses two bounded inverted indexes. High-frequency tokens are pruned and oversized postings are refined/capped; these omissions can lose matches. Per-A/global caps and deterministic drop digests are disclosed. Original unenumerated union counts remain conservative bounds. Computational stress controls are not an accuracy benchmark and prove no blocking recall or match precision.

Rule conflicts and exact product-field evidence checks are implemented. A missing RapidFuzz scorer produces named unavailable, with no replacement implementation. Calibrated probabilities require actual fitted development evidence; none has been fitted. Unsupported calibration requires review. Machine proposals have no human-ruling authority.

Canonical provider/call-ledger, JSONL ruling store, evidence dispatcher and evalkit are installed as unchanged source copies. Offline mock/strict-replay/injected simulation uses real accounting; synthetic captures/prices remain synthetic. The provider successor enforces stored child-purpose checks even when optional caller limits are absent. Product raw-field and journal freshness adapters are functional in source tests. The evalkit supplies frozen-corpus validation, generic statistics and paired group resampling; S4's domain scorer, actual DEV group metadata, fitting and measurement remain pending. Input screening and installed live SDK adapters remain pending. Live Jev/OpenAI access, current pricing, cumulative budget authority and bounded dispatch are separate gates. No credentials or live providers have been exercised.

Raw CSV record IDs allow8192 UTF8 bytes. Canonical ruling IDs allow512 characters; canonical pointer IDs allow256 characters and reject path/URL/control forms. Unsupported identities keep their original strings and visible records/counts, with canonical_identity_unsupported for affected capabilities. No truncation or replacement identity is used. Human-provenance labels alone provide no graph authority. Source tests use an explicitly synthetic validator; actual human evidence and review interactions remain to be established.

The optional API source includes bounded ASGI receiving, exact-origin CORS, a closed original-byte upload wire, a two-workspace in-memory service and a lazy FastAPI factory. Source controls check configured Host/Origin/token before application effects, actual chunk bounds, disconnect/deadline/busy states and canonical page parity. Actual FastAPI/httpx integration, HTTP/browser behavior and server lifecycle have not been exercised. Its 20 MiB ceiling covers the whole base64/JSON request, with less room for raw files than the CLI's per-file bound. Retention accounts for original input bytes rather than measured process memory. The API supplies no journal writer or human admission; token possession/import grants neither. No service or port is started by current commands.

Frozen synthetic DEV/demo fixtures are locally available with exact source hashes and provisional labels; the private heldout snapshot is excluded. Author self-audit is not independent corpus recertification or human agreement. Fitting/tuning/heldout execution, public non-model cohort, accuracy floors, user-flow tests, API/file review round trips, reusable final exports and independent finished-app review remain pending. Bolt import/deployment has not been performed.
