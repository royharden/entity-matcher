## Lessons learned

- Bind raw generations to exact original fields and keep processing configuration separate. Never repair unsupported identifiers by truncation or retargeting.
- Reuse the actual canonical codecs, journal and evaluation primitives. Structural imports and self-reported hashes grant no current-source, journal or human authority.
- Preserve complete intent IDs across uncertain writes. A durable per-event acknowledgement is not batch atomicity, and a tombstone must not revive earlier decisions.
- Root signaling and job accounting are separate observations in both directions. Wait on the same owned handle and allow a bounded same-job drain within the command deadline; lasting descendants still fail. Exact exit/accounting and closure checks are required, and earlier failed observations stay failed.
- A passing parser/unit test, in-process framework test, actual browser flow, genuine person review and quality benchmark are different evidence. Report missing dependencies and unknown probabilities plainly.
- Include malformed input in the runnable journey as well as validator tests. Replaying an old acknowledged decision after a tombstone must preserve the current head and exact journal bytes.
- Network-denial instrumentation must preserve the socket class used by Windows asyncio. Audit hooks after event-loop bootstrap can deny new socket/DNS operations without breaking the loop's existing self pipe; exercise explicit denial controls.
- A launch notice is not readiness. Verify the actual status route, and use the server's `100 Continue` response to establish that a partial upload is holding the body reader before testing concurrent busy refusal.
