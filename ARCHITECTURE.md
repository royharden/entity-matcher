# Current source boundaries

src/entity_matcher is an installed Python package with a keyless setup-state command. shared/match defines immutable models, raw identities, separate normalization/quantity/aliases, bounded candidate retrieval, offline raw judgment signals and exact product-field evidence. io/catalog.py validates in-memory CSV bytes before returning any accepted rows. It has no complete matcher pipeline, journal, service or provider client. web/src is a static React setup preview with root Vite configuration. scripts/check_public_tree.py is a repository guard, not an input-screening or matching library.

Product I/O and review orchestration remain separate from the reusable match module. Generic rulings/evalkit, providers/callledger and evidence dispatch remain owned upstream and require adopted contracts and verified source commits. Stable identities exclude content fingerprints; generation evidence binds raw content separately. Field evidence accepts a supplied retained raw record and accesses no files or URLs. Blocking/cap reports distinguish enumerated counts from bounds on pruned original unions; candidate membership is not match equality.

The product repository contains no agent plans/registries/transcripts, shared workspace imports or runtime data. Dependency locks describe the model/scaffold/testing/frontend tools used now. Future-only OCR, model SDKs, matcher libraries and services are deferred. Model schema validation does not certify calibration, evidence resolution, match correctness or a human decision.
