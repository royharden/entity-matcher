# Current source boundaries

src/entity_matcher is a Python package with read-only validation/candidate commands. shared/match defines immutable models, raw identities, normalization/quantity/aliases, bounded retrieval and offline raw signals. io/catalog.py validates bounded in-memory CSV bytes before accepting rows. calibrate.py and policy.py attach explicit DEV-bound empirical artifacts and emit machine proposals; real fitting remains pending. web/src provides local candidate-report inspection with bounded JSON input, safe text rendering and paging. scripts/check_public_tree.py guards publishable files.

Canonical shared/rulings, shared/cited and shared/providers+callledger are unchanged, licensed source copies with pinned provenance in VENDORED/. Generic evaluation/input-screen modules and live SDK adapters remain pending. The ruling journal is JSONL; the provider ledger is local SQLite. Product domain/bindings.py converts supported identities through those actual codecs. domain/product_rows.py installs exact retained raw-field text resolution with access/current-generation checks. domain/generation.py supplies raw-source freshness to the journal. domain/components.py rebuilds human-evidence-gated positive components and reports internal negative conflicts; it does not consolidate catalogs.

Stable identities exclude fingerprints; raw generation binds exact original fields separately from processing configuration. Human provenance strings alone create no graph edge: an explicit evidence validator must accept the effective current event. Retraction/unsure/stale/provisional heads remain barriers. Raw-current authority survives blocker changes; missing or edited records require review and can split components. Blocking reports separate enumerated counts from bounds on pruned original unions.

The repository contains source and exact promoted synthetic public/DEV fixtures. Runtime data, secrets and agent artifacts stay outside its publishable tree. Python services/model calls and local authoritative persistence remain separate from static hosting. Complete workflow orchestration and a running API are still pending.
